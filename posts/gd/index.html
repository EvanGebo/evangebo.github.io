1 Gradient Descent

We visualize the gradient descent problem in Figure 1:

1.1 Theoretical Analysis

\[\begin{align*} f(\x_{t+1}) &\leq (\x_t) + \nabla f(\x_t)\T(\x_{t+1} - \x_t) + \frac{1}{2}L\|\x_{t+1} - \x_t\|_2^2 \\ &= f(\x_t) + \nabla f(\x_t)\T(\x_t - \alpha \nabla f(\x_t) - \x_t) + \frac{1}{2}L\|\x_t - \alpha\nabla f(\x_t) - \x_t\|_2^2 \\ &= f(\x_t) - \alpha \|\nabla f(\x_t)\|_2^2 + \frac{1}{2}L\|\alpha\nabla f(\x_t)\|_2^2 \\ &= f(\x_t) - \left( 1 - \frac{1}{2}L\alpha \right)\alpha\|\nabla f(\x_t)\|_2^2. \end{align*}\] Now if we assume that \(\alpha \leq \frac{1}{L}\) we see that \[ -\left( 1 - \frac{1}{2}L\alpha \right) = \frac{1}{2}L\alpha - 1 \leq -\frac{1}{2}. \] This simplifies the update step to \[ f(\x_{t+1}) \leq f(\x_t) - \frac{1}{2}\alpha\|\nabla f(\x_t)\|_2^2. \]

2 Learning Rate

The learning rate \(\alpha\) controls how large the gradient updates are: \[ \x^{(t + 1)} \gets \x^{(t)} - \alpha_t \left[\nabla_\x f(\x)\right]_{\x = \x^{(t)}}. \] Changing the learning rate can have some large affects on the performance of the gradient descent algorithm.
